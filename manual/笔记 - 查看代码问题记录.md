## `cv::CommandLineParser` 在做什么

位置：`src/ovsentry_standard_mpc_debug.cpp`

```cpp
const std::string cli_keys =
    "{help h usage ? |                           | 输出命令行参数说明}"
    "{@config-path   | configs/standard3.yaml   | 位置参数，yaml配置文件路径 }";

int main(int argc, char* argv[]) {
    cv::CommandLineParser cli(argc, argv, cli_keys);
    auto config_path = cli.get<std::string>(0);
    if (cli.has("help") || config_path.empty()) {
        cli.printMessage();
        return 0;
    }
    // ...
}
```

`cv::CommandLineParser cli(argc, argv, cli_keys)` 用 OpenCV 的命令行解析器，按 `cli_keys` 的规则解析启动参数。解析结果存在 `cli` 里，后面用 `cli.get` 和 `cli.has` 取出来。

`cli_keys` 里定义了两项：

- `help` / `h` / `usage` / `?`：帮助开关。出现时打印参数说明。
- `@config-path`：第一个位置参数，yaml 配置文件路径，默认 `configs/standard3.yaml`。开头的 `@` 表示它是位置参数，不是 `--xxx` 这种选项。

每一项的写法是 `{名字 | 默认值 | 说明}`。多个名字写在一起，表示它们是同一个开关的不同写法。

后面三行的含义：

- `cli.get<std::string>(0)` 取出第 0 个位置参数，也就是配置文件路径。没在命令行里写时，用默认值 `configs/standard3.yaml`。
- 用户要帮助，或者路径是空的，就调用 `cli.printMessage()` 打印说明并退出。
- 否则，后面的云台、相机、YOLO 等都用这个 `config_path` 去读配置。

用法示例：

- `./程序`：用默认的 `configs/standard3.yaml`
- `./程序 configs/other.yaml`：改用指定的 yaml
- `./程序 -h`：打印参数说明后退出

## `argc` 和 `argv`

这两个参数来自 `main`，是操作系统传进来的原始命令行，解析器靠它们知道你实际输入了什么。

- `argc`（argument count）：参数个数，包含程序名本身。
- `argv`（argument vector）：参数字符串数组。`argv[0]` 是程序名，后面才是你敲进去的参数。

例如执行 `./ovsentry_standard_mpc_debug configs/other.yaml` 时：

- `argc` 为 `2`
- `argv[0]` 为 `./ovsentry_standard_mpc_debug`
- `argv[1]` 为 `configs/other.yaml`

执行 `./ovsentry_standard_mpc_debug -h` 时，`argv[1]` 就是 `-h`。`CommandLineParser` 对照 `cli_keys`，把这些字符串变成配置路径或帮助开关。
