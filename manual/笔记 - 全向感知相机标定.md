笔记：全向感知相机标定 {#note_4}
===============
&emsp;&emsp;全向感知相机固定在底盘上，看向正后方，不随云台转动。标定直接在车上的小电脑上做：后视相机已经用 USB 接在这台小电脑上，两个程序也在这台小电脑上运行。不连接云台，也不读 IMU。
&emsp;&emsp;标定只得到镜头内参 `camera_matrix` 和 `distort_coeffs`。相机朝向 `R_omnicamera2body` 和位置 `t_omnicamera2body` 从机械图读取，写在 `configs/sentry.yaml` 里。装配差几毫米对全向转角没有影响，不再拍外参。
&emsp;&emsp;配置都在 `configs/calibration_omni.yaml`。程序在工程根目录下运行。

### 一、标定前
- 棋盘格内角点 `11 x 8`，格子边长 `30 mm`，和 yaml 里的 `pattern_cols`、`pattern_rows`、`square_size_mm` 一致。
- 在 MVS 里看后视相机序列号，填到 `serial`。留空会打开枚举到的第一台，多台海康同时插着时可能打开主相机。
- 主相机的 `serial` 也要填上，否则它也会去抢第一台设备。
- 画面太暗或太亮时，改 `exposure_ms` 和 `gain`。灰度图里棋盘格要能被认出来。
- 编译两个程序：

```bash
cmake --build build --target capture_chessboard_omni calibrate_camera_omni -j
```

### 二、内参
&emsp;&emsp;内参只和镜头、传感器有关。标定板可以换位置、换角度，车也可以不动。

#### (1) 拍照
- 运行：

```bash
./build/capture_chessboard_omni
```

- 照片默认保存在 `assets/chessboard_calib_omni`，按 `1.jpg`、`2.jpg` 编号。
- 按 `s` 保存，按 `q` 退出。画面提示 `Chessboard found` 才能保存。
- 让标定板在画面里从左到右、从上到下都出现过，距离和倾斜也换几种。至少 15 张，20 张更稳。
- 重拍前先清空这个目录。程序按编号连续读取，中间缺一张就停止，目录里留下的旧照片会被算进去。

#### (2) 计算
- 运行：

```bash
./build/calibrate_camera_omni
```

- 每张图按一次任意键确认。认不出棋盘格的照片会跳过。
- 看重投影误差：小于 `0.5 px` 可用，小于 `0.3 px` 比较好。误差大就补拍或重拍。
- 把打印出的 `camera_matrix` 和 `distort_coeffs` 写入 `configs/sentry.yaml` 里后视相机那一项。

### 三、结果怎么用
- `camera_matrix`、`distort_coeffs` 只写进 `configs/sentry.yaml` 的后视相机。
- `R_omnicamera2body`、`t_omnicamera2body` 按机械图填写，坐标系和电控一致：`x` 朝后，`y` 朝右，`z` 朝上。光轴水平朝后时，现在这组 R 的光轴 yaw 是 `0°`。`t` 单位是 m，顺序是后前、右左、上下。相机在车体右侧时 `y` 为正。
- 转角从车体中心指向装甲板，`0°` 是正后方。主相机在小 yaw 上朝前，发给大小 yaw 的世界角是当前大 yaw加上这个角再加 `180°`。这四项都会读。不要再单独加 `offset_y`。
