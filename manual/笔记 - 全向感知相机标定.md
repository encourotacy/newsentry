笔记：全向感知相机标定 {#note_4}
===============
&emsp;&emsp;全向感知相机固定在底盘上，看向正后方，不随云台转动。标定直接在车上的小电脑上做：后视相机已经用 USB 接在这台小电脑上，三个程序也在这台小电脑上运行。不连接云台，也不读 IMU。
&emsp;&emsp;这一步得到四项：`camera_matrix`、`distort_coeffs`、`R_omnicamera2body`、`t_omnicamera2body`。前两项是镜头内参，后两项是相机相对车体中心的旋转和平移。
&emsp;&emsp;配置都在 `configs/calibration_omni.yaml`。程序在工程根目录下运行。

### 一、标定前
- 棋盘格内角点 `11 x 8`，格子边长 `30 mm`，和 yaml 里的 `pattern_cols`、`pattern_rows`、`square_size_mm` 一致。
- 在 MVS 里看后视相机序列号，填到 `serial`。留空会打开枚举到的第一台，多台海康同时插着时可能打开主相机。
- 主相机的 `serial` 也要填上，否则它也会去抢第一台设备。
- 画面太暗或太亮时，改 `exposure_ms` 和 `gain`。灰度图里棋盘格要能被认出来。
- 编译三个程序：

```bash
cmake --build build --target capture_chessboard_omni calibrate_camera_omni calibrate_extrinsic_omni -j
```

&emsp;&emsp;车体坐标系：原点在车体中心，`x` 朝车头，`y` 朝左，`z` 朝上，单位 m。车尾是负 `x`，右侧是负 `y`。

### 二、内参
&emsp;&emsp;内参只和镜头、传感器有关。标定板可以换位置、换角度，车也可以不动。

#### (1) 拍照
- 运行：

```bash
./build/capture_chessboard_omni
```

- 照片默认保存在 `assets/chessboard_calib_omni`，按 `1.jpg`、`2.jpg` 编号。
- 按 `s` 保存，按 `q` 退出。画面提示 `Chessboard found` 才能保存。
- 让标定板在画面里从左到右、从上到下都出现过，距离和倾斜也换几种。至少 15 张，20 张更稳。
- 重拍前先清空这个目录。程序按编号连续读取，中间缺一张就停止，目录里留下的旧照片会被算进去。

#### (2) 计算
- 运行：

```bash
./build/calibrate_camera_omni
```

- 每张图按一次任意键确认。认不出棋盘格的照片会跳过。
- 看重投影误差：小于 `0.5 px` 可用，小于 `0.3 px` 比较好。误差大就补拍或重拍。
- 把打印出的 `camera_matrix` 和 `distort_coeffs` 写回 `configs/calibration_omni.yaml`。yaml 里现在的数是主相机的，不能拿来算后视相机外参。

### 三、外参
&emsp;&emsp;外参把相机的光轴和位置变到车体中心。光轴不经过车体中心，向右偏的 `136.75 mm` 会进 `t_omnicamera2body`，不要在 `configs/sentry.yaml` 里再用 `offset_y` 加一次。
&emsp;&emsp;后视相机安装时没有俯仰，光轴水平。输出的 `R_omnicamera2body` 只保留绕竖直轴的 yaw，pitch 和 roll 固定为 0，和这个安装一致。

#### (1) 量标定板
- 板放在车尾，竖着放，横边水平，板面朝后视相机。
- 站在相机这一侧看板，量左上角第一个内角点相对车体中心的位置，写入 `board_origin_m`。站在相机这边看，它就是最左上角那一格的右下角。四周都有格子，不是板子外框的角。它通常比外框往里缩至少一个格子，也就是 `30 mm`。三个数都从车体中心量起，不是从相机。例如这个交界点在车体中心后方 `1.20 m`、左右与车体中心对齐、离地 `0.35 m`，就写成 `[-1.20, 0.0, 0.35]`。
- 高度直接量这个内角点离地多高，写入 `z`。现在发出去的俯仰是目标相对水平光轴的角度，车体中心离地多高不参与，不用再减。板竖直、横边水平时，最上面这一行内角点同高，量这一行即可。不要量黑白格的中心，那会差半个格子，也就是 `15 mm`。
- 板面正对相机、横边水平时 `board_yaw_deg` 为 `0`。绕竖直轴让板面朝车体左侧转时为正。
- 从量完到拍完，车和板都不要动。量的是内角点，不是板的外框。

#### (2) 拍照
- 板保持刚才的位姿，再拍几张同一姿态的照片：

```bash
./build/capture_chessboard_omni -o assets/chessboard_calib_omni_extrinsic
```

- 这几张用来取平均。不要和内参照片混在一个目录里。重拍前清空 `assets/chessboard_calib_omni_extrinsic`。

#### (3) 计算
- 运行：

```bash
./build/calibrate_extrinsic_omni
```

- 每张成功的照片会打印平移和光轴的 yaw、pitch。最后打印平均后的 `R_omnicamera2body` 和 `t_omnicamera2body`。
- `t_omnicamera2body` 单位是 m，顺序是前后、左右、上下。后视为负 `x`，相机在车体右侧时 `y` 为负。
- 打印的原始 pitch 超过约 `2°` 时，说明相机没装平。输出的 R 仍然把 pitch 收成 0，需要先把相机调平再标，或者接受这个水平假设。
- 若某张的平移和别的差了接近一块板的尺寸，多半是角点起点认反了。内参不受起点影响，外参受影响。换一下板的朝向或清掉这张再算。

### 四、结果怎么用
- `camera_matrix`、`distort_coeffs` 留在 `configs/calibration_omni.yaml`，外参程序会读它们。
- 把 `camera_matrix`、`distort_coeffs`、`R_omnicamera2body`、`t_omnicamera2body` 写进 `configs/sentry.yaml` 里后视相机那一项。转角从车体中心指向装甲板，这四项都会读。不要再单独加 `offset_y`。
- 机械图上已经有后视相机的位置，并且光轴水平朝正后时，可以直接写 R 和 t，不必再拍外参。正后时 yaw 为 `180°`，`t` 写成实测的前后、左右、上下。
